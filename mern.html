MERN

MERN is a collection of four technologies used to build full-stack web applications. MERN = MongoDB + Express.js + React.js + Node.js

Mongo DB

Stores application data such as users, products, bookings, and passwords (stored securely as hashes).

Express.js

Helps build APIs and handle HTTP requests and responses. Example: Creating a login API.

React.js

Builds the user interface that people see and interact with.Example: Login forms, buttons, and dashboards.

Node.js

Allows JavaScript to run outside the browser, commonly on a server.Example: Running your backend application.
